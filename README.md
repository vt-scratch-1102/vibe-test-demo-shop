# Vibe Test Demo Shop

A tiny **demo** web shop used to try [Vibe Test](https://vibe-test.tech). Nothing here is real: the products are made up, the cart lives in your browser, and checkout takes no payment and sends nothing anywhere.

Pages: product list (`/`), product detail (`/product?id=1`), cart (`/cart`), checkout (`/checkout`).

```bash
npm start   # serves on http://localhost:3000 (or $PORT)
```

No dependencies. Some changes to this repository deliberately carry bugs, so Vibe Test has something to find.
